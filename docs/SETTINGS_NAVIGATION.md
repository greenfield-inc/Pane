# Settings and sidebar navigation

Settings opens as a full-window page. Choose a category in its left navigation (or the category selector in a narrow window), then use **Back** to return to the workspace with its open panels intact. **Usage & Limits** is a settings category and shows the complete usage dashboard.

The expanded workspace sidebar labels the section **Projects** and keeps **New project** at the top. Its full-width **Home** button at the bottom opens the sidebar menu. Choose **Home** there to return to the workspace without an active pane. The same menu contains Help, Settings, sorting, git refresh, Remote, Feedback, Discord, Docs, and About. Remote status and About version details appear in tooltips on hover or keyboard focus, keeping each menu row to one line. The adjacent Settings button opens settings directly. In the compact sidebar, the Home icon still navigates directly and the overflow button opens the menu.
