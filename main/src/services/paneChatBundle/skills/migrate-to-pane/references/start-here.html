4. Are my mistakes reversible?

If I delete my original folder, does it disappear here?
Pane opened your projects where they already were, so your folders are still yours. If you delete one outside Pane, Pane deletes nothing because of it: its Pane stays in the sidebar pointing at the missing folder, and archiving that Pane clears it from the list.
Is my real chat the old one or the new one?
The same conversation. Each session was resumed by its own id with Claude Code's or Codex's own resume, so what you say here continues it. A session that was still running elsewhere came over as a fork: a copy with its own id on a new branch, while the original kept running untouched. A session kept by another tool (Superset, Orca or T3 Code, for example) was copied into your own Claude Code or Codex folder, and continues in that copy. The table above says which happened to each.
What does archiving do?
Archiving a Session hides it from the list and keeps its chat and its Panes. Undo shows for a few seconds, and Archived in the sidebar restores it any time. Archiving a Pane that opened one of your own folders leaves that folder and its branch exactly as they are. Archiving a Pane that Pane created (a fork, or a new task) deletes its folder and keeps its branch: commit first, because uncommitted files in it are not kept.

5. The words

Session
One task's home: its chat, and the Panes doing the work. Sessions are listed in the left sidebar.
Pane
A Pane is a branch: one branch of one project, in its own folder, so agents on different tasks never edit the same files. Panes sit under their Session in the sidebar, named "project · branch".
Tab
One agent or page inside a Pane, shown along the top of the main area. A Pane can run several agents side by side.
Sub-agents
The Panes under a Session are sub-agents its orchestrator agent runs for you. The Session's chat starts them, checks on them and nudges them, so you don't flip between tabs.
