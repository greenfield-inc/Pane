# Canonical license fallback texts

These text files come from the SPDX License List data repository at commit [31ba1a50e5397e00a304dbadc76531740e89ee48](https://github.com/spdx/license-list-data/tree/31ba1a50e5397e00a304dbadc76531740e89ee48/text), fetched on 2026-09-25. Only line endings and trailing whitespace are normalized. They are used offline when a package declares one of these identifiers but supplies neither a license file nor embedded license text.

The generated notice labels these as standard terms. Placeholder copyright fields belong to the SPDX template; they are not assertions about a package's owner. Package-supplied copyright metadata is retained separately when available. Existing package license text always takes precedence.

The SPDX LGPL 3.0 text already includes the incorporated GPL 3.0 terms; the fallback preserves both. Other identifiers or compound expressions are reported as unavailable rather than guessed. These fallbacks do not establish that all required package-specific attribution has been supplied.
